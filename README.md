## 📂 Projetos em Destaque

### 📘 Curso de JavaScript (do zero ao avançado)
Curso estruturado em Markdown, escrito para ser 100% legível direto no GitHub (sem depender de imagens externas).
- Aulas sobre variáveis, tipos, operadores, lógica, estruturas condicionais e algoritmos
- Diagramas em **Mermaid** e visualizações ASCII/texto para funcionar em qualquer visualizador do GitHub
- Módulo completo de **matrizes**: percurso de matrizes bidimensionais, laços aninhados e algoritmos de soma, média, máximo e busca
- Algoritmos clássicos explorados de forma interativa: **Bubble Sort** e **Busca Binária**, com foco em entender laços `for` aninhados

### ☕ Curso de Java Básico
Curso irmão do curso de JavaScript, também organizado por capítulos, com um estilo didático e bem-humorado (referências a livros, frases de cientistas e programadores, e muitos exercícios práticos).
- Fundamentos: variáveis, tipos, `Scanner`, saída no terminal
- Estruturas condicionais (`if`/`else`/`else if`) e de repetição (`for`, `while`, `do-while`)
- Funções e algoritmos clássicos: troca de valores, maior valor e posição, fatorial, Fibonacci, conversão de base, números primos
- `switch case`, vetores (arrays) e técnicas com vetores: inversão, busca linear, busca binária, bubble sort
- Matrizes em Java, incluindo questões em nível de olimpíada (estilo OBI)
- Operador ternário

### 🎮 Space Invaders — Godot Engine
Recriação do clássico jogo de fliperama, construída do zero.
- Desenvolvido em **Godot 4.x** com **GDScript**
- Cena do Player com movimento lateral via Input Map
- Sistema de tiro com `Area2D`, `CollisionShape2D` e detecção de colisão via sinais

### 🎓 CS50 — Introdução à Ciência da Computação (Harvard)
Cursando a versão em português do CS50, com exercícios resolvidos em C.
- Exercícios concluídos: Mario (Less/More), Cash, Credit (algoritmo de Luhn), Population Growth
- Submissões organizadas via `submit50` no repositório `me50/carloseduardorei-alt`

### 🥐 Análise de Dados — Padaria (Projeto UNIFOR)
Projeto analítico aplicando dados a decisões de negócio reais.
- Análise de pedidos e feedbacks de clientes de uma padaria (16+ produtos)
- Classificação de feedbacks por sentimento, urgência e produto
- Relatório formal em Word com tabelas, insights e recomendações práticas de produção, baseado exclusivamente nos dados fornecidos

### 🧪 Outros Projetos Acadêmicos (UNIFOR)
- **PsicoReport** — projeto em equipe (6 integrantes) usando Deep Learning para automatizar a geração de laudos psicológicos conforme as normas do CFP
- **Modelagem de Problemas com Matemática (T100)** — modelos no GeoGebra para interpolação polinomial de terrenos cartográficos e modelagem 3D de uma garrafa via superfícies de revolução
- **Circuitos Digitais** — projeto no Logisim envolvendo registradores de 8 bits, multiplexadores, somador, RAM, contador e buffers controlados
- **BugBank (QA)** — testes estruturados em uma SPA React de prática de testes de software, com casos de sucesso e de borda documentados
