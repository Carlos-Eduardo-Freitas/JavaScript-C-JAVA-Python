# Exercício 1 — Classificando um Triângulo

Escreva um programa em Java que leia três números representando os lados de um triângulo e informe, usando `if`, `else if` e `else`, se o triângulo é:

- **Equilátero** (os três lados iguais);
- **Isósceles** (exatamente dois lados iguais);
- **Escaleno** (todos os lados diferentes).

**Dica:** compare os lados dois a dois usando os operadores `==` e `&&`.

**Exemplo de entrada:**
```
5
5
5
```

**Exemplo de saída:**
```
Triângulo Equilátero
```
