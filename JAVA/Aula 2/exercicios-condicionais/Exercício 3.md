# Exercício 3 — Ano Bissexto

Escreva um programa em Java que leia um ano e informe, usando `if` e `else`, se ele é bissexto.

**Regra:** um ano é bissexto se for divisível por 4 **e** (não for divisível por 100 **ou** for divisível por 400).

**Dica:** combine `%`, `&&` e `||` na mesma condição.

**Exemplo de entrada:**
```
2024
```

**Exemplo de saída:**
```
2024 é um ano bissexto.
```
