# Exercício 5 — Classificando a Faixa Etária

Escreva um programa em Java que leia a idade de uma pessoa e, usando `if`, `else if` e `else`, classifique-a em:

- **Criança:** de 0 a 11 anos
- **Adolescente:** de 12 a 17 anos
- **Adulto:** de 18 a 59 anos
- **Idoso:** 60 anos ou mais

**Exemplo de entrada:**
```
15
```

**Exemplo de saída:**
```
Adolescente
```
