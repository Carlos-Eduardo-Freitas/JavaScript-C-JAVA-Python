# Exercício 2 — Calculadora de Desconto

Uma loja dá desconto de acordo com o valor total da compra:

- Compras acima de R$ 1.000,00: **20%** de desconto
- Compras entre R$ 500,00 e R$ 1.000,00: **10%** de desconto
- Compras abaixo de R$ 500,00: **5%** de desconto

Escreva um programa em Java que leia o valor da compra e exiba o valor do desconto e o valor final a pagar, usando `if` e `else if`.

**Exemplo de entrada:**
```
750.00
```

**Exemplo de saída:**
```
Desconto: R$ 75.00
Valor final: R$ 675.00
```
