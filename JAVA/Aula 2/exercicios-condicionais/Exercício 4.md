# Exercício 4 — Sistema de Login

Escreva um programa em Java que leia um usuário e uma senha digitados, e compare com os valores corretos (`usuario = "admin"` e `senha = "1234"`), usando `if` e `else`.

- Se o usuário **e** a senha estiverem corretos, exiba `"Login realizado com sucesso!"`.
- Caso contrário, exiba `"Usuário ou senha incorretos."`.

**Dica:** lembre-se de usar `.equals()` para comparar `String`, e `&&` para exigir que as duas condições sejam verdadeiras ao mesmo tempo.

**Exemplo de entrada:**
```
admin
1234
```

**Exemplo de saída:**
```
Login realizado com sucesso!
```
